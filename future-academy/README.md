# أكاديمية المستقبل — موقع إلكتروني (يطا، فلسطين)

موقع ثابت (Static Website) بالعربية وباتجاه RTL، مبني بـ HTML / CSS / JavaScript خالص بدون أي إطار عمل أو خطوة بناء (build step) — يكفي رفع الملفات كما هي على أي استضافة.

## الصفحات

| الصفحة | الوصف |
|---|---|
| `index.html` | الصفحة الرئيسية: هيرو، لماذا الأكاديمية، أبرز الخدمات، خطوات الحجز، إحصائيات، آراء الطلاب، التواصل والموقع على الخريطة. |
| `services.html` | كل الخدمات التدريبية مع فلترة حسب التصنيف (تقوية، حاسوب، لغات، قرآن، مهارات، أطفال) + أسئلة شائعة. |
| `booking.html` | نموذج حجز كامل (بيانات شخصية، الدورة والموعد، طريقة الدفع) مع تحقق فوري من الحقول، وصفحة تأكيد تحتوي زر تأكيد عبر واتساب وزر إرسال عبر البريد. |

## الشعار والهوية البصرية

الشعار (`assets/logo-mark.svg`) عبارة عن **شمس مشرقة فوق كتاب مفتوح** بين غصنَي زيتون، مع نجمة تميّز أعلى الشمس:

- **الشمس المشرقة** → ترمز لكلمة "المستقبل".
- **الكتاب المفتوح** → ترمز للعلم والمعرفة ("أكاديمية").
- **غصن الزيتون** → رمز فلسطيني أصيل.
- **النجمة** → التميّز والتفوق.

الشعار SVG قابل للتكبير بلا فقدان جودة، ومستخدم مباشرة كأيقونة (favicon) في كل الصفحات. تم أيضًا توليد نسخ PNG (`favicon-32.png`, `apple-touch-icon.png`, `icon-512.png`) من نفس الملف.

| اللون | القيمة | الاستخدام |

كل المتغيرات موجودة في أعلى ملف `css/style.css` (`:root { --navy, --gold, --olive, ... }`) — تغييرها من مكان واحد يغيّر ألوان الموقع كاملة.

### الخط
الخط المستخدم هو **Cairo** من Google Fonts (يدعم العربية بعناية ووزنه يمتد من 400 إلى 900)، محمّل عبر `<link>` في كل صفحة.

## بيانات تجريبية يجب تعديلها قبل النشر

كل ما يلي بيانات **مبدئية (Placeholder)** ويجب استبدالها ببيانات الأكاديمية الحقيقية قبل إطلاق الموقع:

- **رقم الهاتف / واتساب**: `+970 59 900 0000` (يظهر في الهيدر، الفوتر، زر واتساب العائم، وصفحة الحجز).
- **البريد الإلكتروني**: `info@future-academy-yatta.ps` و `booking@future-academy-yatta.ps` (في `js/main.js`).
- **العنوان**: "الشارع الرئيسي، يطا - محافظة الخليل" — استبدله بعنوان دقيق (اسم الشارع، أقرب معلم).
- **روابط التواصل الاجتماعي**: `#` في فيسبوك/إنستغرام/تيك توك — ضع الروابط الحقيقية.
- **خريطة Google Maps**: مضمّنة حاليًا بالبحث عن "Yatta, Palestine". لتحديد الموقع بدقة أكبر، افتح Google Maps → ابحث عن موقع الأكاديمية → مشاركة → "تضمين خريطة" → انسخ رابط `src` وضعه في `<iframe>` داخل `index.html`.
- **الإحصائيات** (+600 طالب، +18 دورة، إلخ) والشهادات في قسم "آراء طلابنا" في `index.html` هي **نماذج توضيحية** — استبدلها بأرقام وآراء حقيقية من طلاب الأكاديمية.
- **أسعار الدورات ومددها** في `services.html` تقديرية — حدّثها حسب الأسعار الفعلية.

## طريقة الدفع في نموذج الحجز

نموذج الحجز (`booking.html`) يعرض 3 خيارات دفع:
1. **الدفع نقدًا** في مقر الأكاديمية.
2. **تحويل بنكي / محفظة إلكترونية** (مثل جوال باي) — يُنصح بإضافة رقم الحساب البنكي أو المحفظة الفعلي داخل صندوق `pay-detail[data-for="transfer"]` في `booking.html`.
3. **الدفع لاحقًا** عند تأكيد الحجز هاتفيًا.

## كيف يعمل نموذج الحجز؟ (بدون خادم/باك-إند)

الموقع **ثابت بالكامل** بدون قاعدة بيانات أو خادم. عند إرسال نموذج الحجز:
1. يتحقق JavaScript (`js/main.js`) من صحة الحقول (الاسم، رقم جوال فلسطيني، بريد إلكتروني إن وُجد، الموافقة على الشروط).
2. تظهر بطاقة تأكيد تلخّص بيانات الحجز.
3. يحصل الزائر على زرّين:
   - **تأكيد عبر واتساب**: يفتح محادثة واتساب مع رقم الأكاديمية ورسالة معبأة تلقائيًا بكل تفاصيل الحجز.
   - **إرسال عبر البريد**: يفتح برنامج البريد الافتراضي برسالة معبأة بنفس التفاصيل.

هذا يعني أن كل حجز يحتاج تأكيد المستخدم بالضغط على أحد الزرّين ليصل فعليًا لصاحب الأكاديمية. **لأتمتة استقبال الحجوزات مباشرة** (تخزينها في قاعدة بيانات أو إرسالها تلقائيًا بالبريد)، يمكن لاحقًا ربط النموذج بخدمة مثل:
- [Formspree](https://formspree.io) أو [Web3Forms](https://web3forms.com) (إرسال بريد تلقائي بدون خادم خاص).
- Cloudflare Worker / Netlify Functions بسيطة تستقبل بيانات النموذج وتخزنها أو ترسلها.

## النشر (Deployment)

الموقع ثابت بالكامل، يمكن نشره فورًا على أي من:
- **Cloudflare Pages**: اسحب مجلد `future-academy` كموقع جديد (Build command: فارغ، Output directory: `/`).
- **Netlify**: اسحب المجلد مباشرة على [app.netlify.com/drop](https://app.netlify.com/drop).
- **GitHub Pages**: فعّل Pages على هذا المستودع واختر مجلد `future-academy` (أو انقل المحتوى لجذر مستودع منفصل).
- أو ببساطة افتح `index.html` مباشرة في المتصفح للمعاينة المحلية.
