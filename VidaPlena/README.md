# 🌿 Vida Plena - Mobile App

**Vida Plena** is a multi-language wellness marketplace app built with Expo and React Native. It connects users with real health specialists (therapists, coaches, nutritionists, yoga instructors) and provides wellness features for work-life balance.

## 🌍 Language Support
- 🇬🇧 **English** - Development language
- 🇪🇸 **Spanish** - Main market (Spain)
- 🇸🇦 **Arabic** - Arab community in Spain

## 📱 Tech Stack
- **Framework:** React Native + Expo
- **Navigation:** React Navigation (Bottom Tab Navigator)
- **Internationalization:** i18next + react-i18next
- **State Management:** React Hooks
- **Styling:** React Native StyleSheet

## 🚀 Quick Start

### Prerequisites
- Node.js 16+ and npm/yarn installed
- Expo CLI installed (`npm install -g expo-cli`)

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm start
```

### Run on Device/Emulator

```bash
# Android emulator
npm run android

# iOS simulator (macOS only)
npm run ios

# Web browser
npm run web
```

## 📚 Features Implemented (Phase 1)

### ✅ Dashboard Screen
- Greeting message with time-based emoji
- Wellness stats (Stress Level, Family Time, Wellness Score, Sleep)
- Quick action buttons (Meditation, Quick Rest, Water Reminder)
- Daily wellness tips
- Call-to-action for booking therapy sessions

### ✅ Therapy Screen (Marketplace)
- Search therapists by name
- Filter by specialty (All, Psychologist, Life Coach, Nutritionist, Yoga Instructor)
- View specialist profiles with ratings, experience, and pricing
- Book appointment button (placeholder)

### ✅ Multi-Language Support
- Full translations for English, Spanish, and Arabic
- i18n support ready for any screen

### ✅ Bottom Tab Navigation
- Dashboard, Therapists, My Sessions, Community, Profile

## 💰 Revenue Model

**Marketplace Model:**
- Users pay €60/session
- App takes 30% commission = €18
- Specialist gets 70% = €42

**Expected Revenue:** €15K-30K/month at scale
