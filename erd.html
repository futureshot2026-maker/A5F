🏥 Entity Relationship Diagram - مركز طبي يطا

وصف هيكل قاعدة البيانات

يوضح هذا المخطط (ERD) العلاقات بين جميع جداول قاعدة البيانات الرئيسية للمركز الطبي. يشتمل على:

  • جدول المرضى (Patients): معلومات المريض الشخصية والطبية
  • جدول الموظفين (Staff): بيانات الأطباء والفنيين والموظفين
  • جدول المواعيد (Appointments): حجوزات المواعيد وجدولة الخدمات
  • جدول الخدمات (Services): قائمة الخدمات الطبية المتاحة
  • جداول المختبرات (Lab Tests & Results): فحوصات وتحاليل الدم
  • جداول الأشعات (Radiology Exams & Reports): تقارير الأشعات
  • جدول الطوارئ (Emergency Visits): زيارات الطوارئ
  • جدول الدفعات (Payments): معاملات الدفع
  • جدول السجلات الطبية (Medical Documents): الملفات والتقارير
  • جدول سجل المراجعة (Audit Log): تتبع جميع العمليات

📊 جداول قاعدة البيانات التفصيلية

👥 Patients

  • id (المعرّف الفريد)
  • first_name / last_name
  • email / phone
  • date_of_birth
  • medical_history
  • allergies
  • insurance info
  • password (محمي)

👨‍⚕️ Staff

  • id
  • first_name / last_name
  • email / phone
  • role (doctor, nurse, etc.)
  • specialization
  • department
  • license_number
  • employment_date

🏥 Services

  • id
  • name (اسم الخدمة)
  • code (رمز فريد)
  • category (emergency, lab, radiology)
  • price
  • duration_minutes
  • requires_fasting
  • status

📅 Appointments

  • id
  • patient_id (FK)
  • service_id (FK)
  • staff_id (FK)
  • appointment_date
  • appointment_time
  • status (scheduled, confirmed, completed)
  • notes

🧪 Lab Tests

  • id
  • appointment_id (FK)
  • test_name
  • test_code
  • specimen_type
  • specimen_collected_at
  • status (ordered, processing, completed)

📊 Lab Results

  • id
  • lab_test_id (FK)
  • patient_id (FK)
  • test_parameter
  • result_value
  • normal_range
  • status (normal, abnormal)
  • verified_by / verified_at

🖼️ Radiology Exams

  • id
  • appointment_id (FK)
  • patient_id (FK)
  • exam_type
  • modality (xray, ct, mri, ultrasound)
  • body_part
  • exam_date
  • images_count

📋 Radiology Reports

  • id
  • radiology_exam_id (FK)
  • patient_id (FK)
  • radiologist_id
  • report_text
  • findings
  • impressions
  • status (draft, approved)

🚑 Emergency Visits

  • id
  • patient_id (FK)
  • arrival_time
  • triage_level (red, yellow, green)
  • chief_complaint
  • vital_signs (temp, bp, heart_rate)
  • treatment_provided
  • disposition

💳 Payments

  • id
  • patient_id (FK)
  • appointment_id (FK)
  • amount
  • currency
  • payment_method
  • status (pending, completed, failed)
  • transaction_id

📄 Medical Documents

  • id
  • patient_id (FK)
  • appointment_id (FK)
  • document_type
  • document_path
  • file_size
  • mime_type
  • visibility (private, patient, shared)

📝 Audit Log

  • id
  • user_id
  • user_type (patient, staff)
  • action
  • entity_type
  • entity_id
  • ip_address
  • status (success, failure)

⚙️ Settings

  • id
  • setting_key (اسم الإعداد)
  • setting_value
  • setting_type
  • updated_at

🔐 ميزات الأمان والبيانات

  • التشفير: تشفير كامل لكلمات المرور وبيانات حساسة
  • Foreign Keys: ارتباطات قوية لضمان تكامل البيانات
  • Indexes: فهارس على الحقول المستخدمة للبحث والترتيب
  • Audit Log: تسجيل كل العمليات للمراجعة والمتابعة
  • Timestamps: created_at و updated_at على جميع الجداول
  • Status Tracking: تتبع حالة كل سجل (active, inactive, archived)
  • Views: مشاهد محمية للوصول الآمن للبيانات
  • HIPAA Compliance: معايير حماية بيانات صحية دولية
