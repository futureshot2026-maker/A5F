# أكاديمية المستقبل — Future Academy

موقع تعليمي متكامل لأكاديمية تدريب مهني في مجالات **الكوافير والتجميل**، يتضمن:

- صفحة رئيسية (`public/index.html`)
- صفحة الدورات/الخدمات مع نموذج حجز مربوط بالدفع (`public/services.html`)
- شعار مصمم خصيصًا (`public/assets/logo.svg`)
- هوية بصرية بألوان دافئة (كستنائي/ذهبي/وردي فاتح) تناسب قطاع الجمال

## الهيكل

```
public/          الموقع الثابت (HTML/CSS/JS + الشعار)
server/          خادم Node/Express يخدم الموقع وينشئ جلسات الدفع عبر Stripe
```

## التشغيل محليًا

```bash
cd server
cp .env.example .env   # ثم عدّلي القيم
npm install
npm start
```

افتحي المتصفح على `http://localhost:3000`.

## ربط الدفع (Stripe)

1. أنشئي حسابًا على https://dashboard.stripe.com
2. انسخي `Secret key` من صفحة API keys وضعيها في `server/.env` باسم `STRIPE_SECRET_KEY`
3. (اختياري) لتفعيل تأكيد الدفع التلقائي عبر Webhook: أنشئي webhook يشير إلى
   `https://<your-domain>/api/stripe-webhook` وضعي السر الناتج في `STRIPE_WEBHOOK_SECRET`
4. دون مفتاح Stripe، يعمل نموذج الحجز بشكل طبيعي لكن يتحول تلقائيًا لخيار
   "الحجز والتواصل لإتمام الدفع" بدلاً من تحويل الطالبة لصفحة الدفع.

أسعار الدورات مصدرها الوحيد هو `server/courses.js` — أي تعديل على الأسعار أو
إضافة دورة جديدة يتم من هذا الملف فقط، وتنعكس تلقائيًا في صفحة الخدمات
ونموذج الحجز.

## بيانات الحجوزات

كل حجز (سواء عبر الدفع الفوري أو "الدفع لاحقًا") يُحفظ في `server/bookings.json`
ليتمكن فريق الأكاديمية من المتابعة. لبيئة إنتاج حقيقية يُنصح باستبدال هذا
الملف بقاعدة بيانات (Supabase / MongoDB / PostgreSQL).

## النشر

يمكن نشر الموقع على أي منصة تدعم Node.js (Render, Railway, Fly.io, VPS...).
المجلد `public/` هو الواجهة الثابتة ويُخدَّم مباشرة من `server/server.js`.

بعد النشر، حدّثي:
- `SITE_URL` في `.env` بعنوان الموقع الفعلي (يُستخدم في روابط نجاح/إلغاء الدفع)
- رقم واتساب الأكاديمية في `public/js/booking.js` (`WHATSAPP_NUMBER`) وكل روابط
  `wa.me` في صفحات `index.html` و `services.html`
- بيانات التواصل (العنوان، الهاتف، البريد) في تذييل وقسم "تواصل معنا"
