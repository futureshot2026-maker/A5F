## 📋 الملفات الرئيسية

### **index.html** - الصفحة الرئيسية
- الشريط العلوي (Navigation Bar)
- قسم البطل (Hero Section)
- عرض الخدمات الثلاث
- نموذج الحجز السريع
- قسم من نحن
- جدول الأسعار
- أسئلة شائعة
- نموذج التواصل
- الصفحة السفلية (Footer)

### **styles.css** - التصاميم
- تصميم متجاوب (Mobile-First)
- ألوان معايير طبية (أزرق، أخضر، أحمر)
- أنيميشنات سلسة
- دعم الأجهزة المختلفة
- وضع مظلم (Dark Mode) جاهز

### **script.js** - الوظائف التفاعلية
- حجز المواعيد
- التحقق من البيانات
- تبديل قائمة الهاتف
- أسئلة شائعة (Accordion)
- أزرار التمرير السلس
- تتبع الأداء (Performance)
- واجهات API جاهزة للبيئة الإنتاجية

### **database.sql** - قاعدة البيانات
14 جدول رئيسي:
1. **patients** - بيانات المرضى
2. **staff** - الموظفون والأطباء
3. **services** - الخدمات المتاحة
4. **appointments** - المواعيد
5. **lab_tests** - الفحوصات المختبرية
6. **lab_results** - نتائج الفحوصات
7. **radiology_exams** - الفحوصات الإشعاعية
8. **radiology_reports** - تقارير الأشعات
9. **emergency_visits** - زيارات الطوارئ
10. **payments** - الدفعات
11. **medical_documents** - الملفات الطبية
12. **audit_log** - سجل المراجعة
13. **contact_messages** - رسائل التواصل
14. **settings** - الإعدادات

### **erd.html** - مخطط العلاقات
- رسم توضيحي كامل للعلاقات
- وصف كل جدول
- الحقول والأنواع
- العلاقات (1:1, 1:N, N:N)

## 🛠️ التثبيت والإعداد

### المتطلبات
- PHP 7.4+ أو Node.js 14+
- MySQL 5.7+
- SSL Certificate (HTTPS)
- Web Server (Apache/Nginx)

### خطوات التثبيت

#### 1. استنساخ المشروع
```bash
git clone https://github.com/yourusername/medical-center-website.git
cd medical-center-website
```

#### 2. إنشاء قاعدة البيانات
```bash
mysql -u root -p < database.sql
```

#### 3. تكوين الإعدادات
```bash
cp config.example.php config.php
# ثم عدّل config.php بالبيانات الخاصة بك
```

#### 4. تثبيت المتطلبات (إذا كنت تستخدم Backend)
```bash
composer install  # للـ PHP
npm install       # للـ Node.js
```

#### 5. تشغيل المشروع
```bash
# للـ PHP
php -S localhost:8000

# أو استخدم Apache/Nginx
```

#### 6. فتح في المتصفح
```
http://localhost:8000
```
