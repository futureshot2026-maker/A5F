# موقع أكاديمية المستقبل للتدريب المهني — يطا، فلسطين

موقع إلكتروني كامل ومستجيب (Responsive) باللغة العربية واتجاه RTL، بتصميم مودرن مينيماليست
مبني على هوية بصرية جديدة (شعار + لوحة ألوان)، ونظام تسجيل ودفع إلكتروني عبر **PayPal** أو **تحويل بنكي**.

## الصفحات

| المسار | الصفحة | المحتوى |
|---|---|---|
| `/` | الرئيسية | هيرو، أقسام التدريب، لماذا نحن، الدورات المميزة، خطوات التسجيل، طرق الدفع، آراء المتدربات، الأسئلة الشائعة |
| `/about/` | عن الأكاديمية | القصة، الأرقام، الرؤية والرسالة والقيم، ما يميّزنا، فريق التدريب، الاعتماد والشراكات |
| `/services/` | الدورات والخدمات | كتالوج الدورات مع فلترة حسب القسم، الاستشارات المهنية، أسعار الصالون التدريبي، الخدمات الإضافية |
| `/contact/` | حجز استشارة | نموذج حجز الاستشارة (Contact Form) + بيانات التواصل + تفاصيل التحويل البنكي |
| `/booking/` | التسجيل والدفع | نموذج التسجيل في دورة + حساب الرسوم + اختيار طريقة الدفع |
| `/booking/success.html` | تأكيد الطلب | تنفيذ تحصيل PayPal بعد العودة من البوابة، أو عرض تعليمات التحويل البنكي |
| `/booking/cancel.html` | إلغاء الدفع | رسالة إلغاء مع الاحتفاظ بالرقم المرجعي |

## الهوية البصرية

الشعار مصمَّم داخل المشروع كملفات SVG (`public/assets/`): مربع محدّب بلون التيل العميق
يحتضن حرف **A** صاعدًا كسهم نحو المستقبل، بلمسة ذهب نحاسي.

| الدور | اللون |
|---|---|
| اللون الأساسي (تيل عميق) | `#0E3B38` |
| التيل المتوسط / اللون المميّز | `#1E8177` |
| الذهب النحاسي | `#D9B36A` — `#A87C2C` |
| الحبري (الفوتر) | `#0B1A19` |
| الخلفيات المحايدة | `#FBFAF7` / `#F0EDE5` |

الخطوط: **Almarai** للعناوين و**Tajawal** للنصوص.

## الأسعار والعملة

الأسعار معروضة بالشيكل (₪) في `public/data/courses.json`، وهو **المصدر الوحيد** للأسعار:
المتصفح يعرض منها، والخادم يعيد حساب كل مبلغ منها قبل إنشاء أي عملية دفع، فلا يُقبل أي مبلغ قادم من المتصفح.

> **ملاحظة مهمة:** PayPal لا يدعم الشيكل الإسرائيلي (ILS) كعملة تحصيل، لذلك يتم التحصيل
> بالدولار الأمريكي وفق سعر التحويل `usdRate` (أو المتغير `USD_RATE`)، ويُعرض المبلغ بالعملتين
> للمستخدمة قبل التحويل إلى صفحة الدفع. التحويل البنكي والدفع في المقر يتمّان بالشيكل مباشرة.

## واجهات API

| المسار | الطريقة | الوظيفة |
|---|---|---|
| `/api/health` | GET | حالة الخدمة وهل الدفع مفعّل |
| `/api/courses` | GET | كتالوج الدورات والاستشارات |
| `/api/booking` | POST | تسجيل في دورة → رابط PayPal أو بيانات التحويل أو حجز بالدفع في المقر |
| `/api/consultation` | POST | طلب استشارة (مجانية أو مدفوعة) |
| `/api/paypal/capture` | POST | تحصيل الدفعة بعد عودة المستخدمة من PayPal |
| `/api/paypal/webhook` | POST | إشعارات PayPal (يتم التحقق من التوقيع لدى PayPal) |
| `/api/order/status` | GET | حالة طلب بالرقم المرجعي (يتطلب KV) |

طرق الدفع المدعومة في `/api/booking`:

- `payment`: `full` (كامل الرسوم) · `deposit` (عربون 30%) · `cash` (دفع في المقر)
- `method`: `paypal` · `bank` · `cash`

## التشغيل محليًا

```bash
cd academy
npm install
cp .dev.vars.example .dev.vars   # ثم املأ مفاتيح PayPal إن رغبت بتجربة الدفع
npm run dev                      # يشغّل الموقع + واجهات API على wrangler
```

لمعاينة الصفحات الثابتة فقط دون Worker:

```bash
npm run preview
```

بدون مفاتيح PayPal يعمل الموقع في **وضع تجريبي**: يُسجَّل الطلب ويُعطى رقمًا مرجعيًا،
مع رسالة توضّح أن بوابة الدفع قيد التفعيل. أما التحويل البنكي والدفع في المقر فيعملان دائمًا.

## تفعيل الدفع عبر PayPal

1. أنشئ تطبيق REST من [PayPal Developer](https://developer.paypal.com/dashboard/applications).
2. خزّن المفاتيح كأسرار:
   ```bash
   npx wrangler secret put PAYPAL_CLIENT_ID
   npx wrangler secret put PAYPAL_SECRET
   ```
3. عند الانتقال للإنتاج اضبط `PAYPAL_ENV=live` في `wrangler.jsonc`.
4. (اختياري) أنشئ Webhook على الحدث `PAYMENT.CAPTURE.COMPLETED` بالمسار
   `https://<نطاقك>/api/paypal/webhook`، ثم خزّن `PAYPAL_WEBHOOK_ID`.

## تفعيل التحويل البنكي

حدّث بيانات الحساب في `public/data/courses.json` تحت `meta.bank`،
أو تجاوزها بمتغيرات البيئة `BANK_NAME` و`BANK_ACCOUNT_NAME` و`BANK_ACCOUNT_NO` و`BANK_IBAN` و`BANK_SWIFT`.
يظهر للمستخدمة رقم مرجعي تكتبه في خانة البيان، وتُرسل صورة الإيصال عبر واتساب لتثبيت الحجز.

## حفظ الطلبات (اختياري)

```bash
npx wrangler kv namespace create BOOKINGS
```
ثم فعّل `kv_namespaces` في `wrangler.jsonc`. بدون KV تعمل جميع النماذج، لكن دون أرشفة الطلبات
(يُنصح عندها بضبط `NOTIFY_WEBHOOK_URL` لاستقبال كل طلب على بريدك أو أداة أتمتة).
