# موقع أكاديمية المستقبل للتعليم المهني

موقع كامل لأكاديمية كوافير ودورات تجميل: صفحة رئيسية، صفحة دورات وخدمات،
ونموذج حجز مربوط ببوابة دفع إلكتروني — بواجهة عربية RTL وتصميم عصري متجاوب.

---

## 1) محتويات المشروع

```
academy/
├── worker.js              واجهات API (الحجز، حالة الدفع، ويب هوك Stripe)
├── wrangler.jsonc         إعدادات النشر على Cloudflare Workers
├── package.json           أوامر التشغيل والنشر
├── .dev.vars.example      نموذج المتغيرات السرية
└── public/                ملفات الموقع الثابتة
    ├── index.html             الصفحة الرئيسية
    ├── services/index.html    الدورات والخدمات
    ├── booking/index.html     نموذج الحجز والدفع
    ├── booking/success.html   تأكيد الحجز / نتيجة الدفع
    ├── booking/cancel.html    إلغاء الدفع
    ├── 404.html               صفحة غير موجودة
    ├── data/courses.json      كتالوج الدورات والأسعار (مصدر واحد للحقيقة)
    ├── assets/                الشعار والأيقونة (SVG)
    ├── css/style.css          نظام التصميم الكامل
    └── js/site.js, booking.js سكربتات الموقع والنموذج
```

## 2) الهوية البصرية

**الشعار** (`public/assets/logo-mark.svg` و `logo-full.svg` و `favicon.svg`) مرسوم بصيغة SVG
قابلة للتكبير بلا فقدان جودة: مرآة تجميل ذهبية بداخلها بتلة وردية، داخل شارة بنفسجية متدرجة
مع لمسة بريق — رمز يجمع بين الأنوثة والحرفية، ويبقى واضحًا حتى بحجم 32 بكسل.

**لوحة الألوان** (معرّفة كمتغيرات CSS في `public/css/style.css`):

| المتغير | اللون | الاستخدام |
|---|---|---|
| `--plum` / `--plum-2` | `#3A1B44` / `#4A1F52` | الأساس البنفسجي الفاخر، العناوين |
| `--orchid` | `#7A2A63` | تدرجات الأقسام والأسعار |
| `--rose` | `#E2537B` | لون الحركة (الأزرار، الروابط الفاعلة) |
| `--gold` / `--gold-deep` | `#E3B778` / `#C1863F` | لمسات ذهبية، أزرار ثانوية |
| `--cream` / `--sand` | `#FDF8F5` / `#F6EAE1` | خلفيات فاتحة مريحة للقراءة |

**الخطوط:** `Almarai` للعناوين و `Tajawal` للنصوص من Google Fonts.

## 3) التشغيل محليًا

```bash
cd academy
npm install
npm run dev            # Cloudflare Worker + الموقع على http://localhost:8787
```

لمعاينة الواجهة فقط بدون واجهات API:

```bash
npm run preview        # خادم ثابت على http://localhost:4173
```

> بدون مفتاح Stripe يعمل نموذج الحجز في **وضع تجريبي**: يُسجَّل الطلب ويُعطى رقمًا مرجعيًا
> مع رسالة بأن بوابة الدفع قيد التفعيل، دون أي عملية دفع فعلية.

## 4) تفعيل الدفع الإلكتروني (Stripe)

1. أنشئ حسابًا على [stripe.com](https://stripe.com) وفعّل طرق الدفع المطلوبة (مدى، فيزا، ماستركارد، Apple Pay).
2. أضف المفتاح السري:
   ```bash
   npx wrangler secret put STRIPE_SECRET_KEY      # sk_live_… أو sk_test_…
   ```
3. (مستحسن) أنشئ Webhook في لوحة Stripe على المسار `https://<نطاقك>/api/stripe/webhook`
   لحدث `checkout.session.completed`، ثم أضف سرّه:
   ```bash
   npx wrangler secret put STRIPE_WEBHOOK_SECRET  # whsec_…
   ```
4. (اختياري) لاستقبال بيانات كل حجز على نظامك أو على Zapier/Make/n8n:
   ```bash
   npx wrangler secret put NOTIFY_WEBHOOK_URL
   ```
5. (اختياري) لحفظ الحجوزات: أنشئ KV Namespace وفعّل ربط `BOOKINGS` في `wrangler.jsonc`.

**ملاحظة أمنية:** المبالغ تُحسب في الخادم فقط انطلاقًا من `data/courses.json`،
ولا يُقبل أي سعر قادم من المتصفح. بيانات البطاقات لا تمر على الخادم إطلاقًا —
الدفع يتم داخل صفحة Stripe Checkout المستضافة.

## 5) واجهات API

| المسار | الطريقة | الوظيفة |
|---|---|---|
| `/api/health` | GET | فحص التشغيل وحالة تفعيل الدفع |
| `/api/courses` | GET | كتالوج الدورات |
| `/api/booking` | POST | إنشاء حجز وإرجاع رابط الدفع (أو تأكيد الحجز بدون دفع) |
| `/api/booking/status?session_id=` | GET | التحقق من حالة الدفع بعد العودة من البوابة |
| `/api/stripe/webhook` | POST | استقبال تأكيد الدفع من Stripe (بتحقق من التوقيع) |

## 6) قواعد التسعير المطبّقة

- خصم مجموعة **10%** تلقائيًا عند حجز **3 مقاعد فأكثر** (بحد أقصى 5 مقاعد للطلب الواحد).
- **عربون 30%** لتثبيت المقعد، والباقي يُسدَّد أول يوم تدريب.
- خيار **الحجز والدفع في المقر** يحجز المقعد 48 ساعة دون دفع إلكتروني.

## 7) تعديل المحتوى

- **الدورات والأسعار:** `public/data/courses.json` فقط — تنعكس تلقائيًا على الصفحة
  الرئيسية وصفحة الخدمات وقائمة نموذج الحجز وحسابات الخادم.
- **بيانات التواصل:** رقم الهاتف والبريد والعنوان ورابط واتساب في تذييل صفحات HTML
  (ابحث عن `966500000000` و `info@future-academy.example` لتغييرهما دفعة واحدة).
- **العملة:** الحقل `meta.currency` و `meta.symbol` في `courses.json` (الافتراضي `SAR` / `ر.س`).
- قبل الإطلاق: حدّث النطاق في `public/robots.txt` و `public/sitemap.xml`.

## 8) النشر

```bash
npx wrangler deploy
```

يمكن أيضًا استضافة مجلد `public/` على أي خدمة ملفات ثابتة، مع ملاحظة أن نموذج الدفع
يحتاج إلى تشغيل `worker.js` (أو ما يعادله) لتوفير مسارات `/api/*`.
